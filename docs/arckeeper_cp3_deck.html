How · Autonomous Loop

arc-rebalance --watch

Every --interval seconds the agent: reads the on-chain USDC balance → decides against a threshold band → acts. No human in the loop.

📊 Read

Arc RPC → USDC.balanceOf(agent) every tick.

🧠 Decide

Band [floor, ceiling] → SAFE / WARNING / DANGER.

✍️ Act

Below floor → top-up; above ceiling → sweep.

python -m src.main arc-rebalance --watch --interval 30 --backend circle # tick 1 balance 42.1 → SAFE (within [40, 60]) # tick 2 balance 63.4 → SWEEP 3.4 → reserve (above ceiling) # tick 3 balance 36.2 → TOPUP 3.8 → operational (below floor)
Custody · Circle Agent Stack

Pluggable WalletBackend

One env var ARC_WALLET_BACKEND=circle swaps the local key for a Circle developer-controlled wallet on ARC-TESTNET. Same rebalancer code — different custody.

🔑 LocalKeyBackend

Signs with eth_account, broadcasts via Arc RPC. Zero external deps (default).

🏦 CircleWalletBackend

USDC held in Circle custody. Transfers authorised through Circle's API, which enforces the wallet's spending policy server-side — daily caps, allow/block lists.

stdlib urllib → Circle REST (developer/transactions/transfer on ARC-TESTNET). No third-party SDK.

Safety rails

Built to not blow up

🛡️ Per-action guards

  • max_rebalance_usd cap ($10k default) on every move
  • Chain-id binding — Arc only
  • EIP-55 checksum + monotonic nonces
  • Idempotent retry on transient failures

🔁 Loop guards

  • Auto-stop after N consecutive errors
  • Exponential back-off between ticks
  • Dry-run by default; --execute to broadcast
  • 64 unit tests green (CP3 suite)
