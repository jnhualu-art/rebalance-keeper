ArcKeeper

Autonomous USDC Treasury on Arc

An on-chain agent that monitors a USDC treasury and rebalances it without a human in the loop — using signed EIP-1559 transactions, threshold logic, and zero external dependencies.

Why

Problem → Solution

❌ Today

Stablecoin treasuries are managed by hand — humans watch dashboards, copy-paste addresses, sign txs.

Slow, error-prone, fails at 3am when risk spikes.

✅ ArcKeeper

An agent that watches the on-chain USDC balance, decides based on a threshold band, and signs & broadcasts the move itself.

Truly autonomous — agent is its own custodian.
